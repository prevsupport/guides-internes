Page en paysage dans un document

Isoler l'orientation d'une seule page — OnlyOffice & Word

← Menu
🎯

Objectif

Obtenir un document où une seule page est en orientation paysage, sans modifier l'orientation des autres pages.

  • Page 1 → Portrait
  • Page 2 → Paysage
  • Page 3 et toutes les suivantes → Portrait
Point important : deux sauts de section sont nécessaires — un avant la page paysage et un après. Un simple saut de page ne permet pas d'isoler l'orientation d'une seule page ; il faut un saut de section.
➕

Créer une section avant la page paysage Étape 1/4

Sur la page 1, placer le curseur à la fin du contenu.

OnlyOffice
Mise en page → Saut de page ▼ → Insérer saut de section → Page suivante
Word
Mise en page → Sauts ▼ → Sauts de section → Page suivante
Cela crée une nouvelle section à partir de la page 2.
OnlyOffice — Mise en page → Saut de page → Insérer saut de section → Page suivante.
Word — Mise en page → Sauts de page → Sauts de section → Page suivante.
🔄

Passer la page 2 en paysage Étape 2/4

Placer le curseur sur la page 2.

OnlyOffice
Mise en page → Orientation → Paysage
Word
Mise en page → Orientation → Paysage
La section contenant la page 2 passe alors en paysage — les autres sections ne sont pas affectées.
OnlyOffice — Mise en page → Orientation → Portrait / Paysage.
Word — Mise en page → Orientation → Portrait / Paysage.
➕

Créer une section après la page paysage Étape 3/4

Placer le curseur à la fin de la page 2.

OnlyOffice & Word
Mise en page → Saut(s) de page ▼ → Saut de section → Page suivante
Même manipulation qu'à l'étape 1 — voir les captures ci-dessus.
La page 3 devient alors le début d'une nouvelle section.
🔄

Repasser la page 3 en portrait Étape 4/4

Placer le curseur sur la page 3.

OnlyOffice & Word
Mise en page → Orientation → Portrait
Comme la page 3 constitue une nouvelle section, les pages suivantes restent également en portrait.
✅
